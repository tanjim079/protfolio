# Sheikh Tanjim Ahmed - Personal Portfolio

![Portfolio Preview](./src/assets/hero.png) *(Preview image)*

Welcome to the source code of my personal developer portfolio! This portfolio is designed to showcase my projects, skills, education, and experiences as a Full-Stack Web Developer and Electronics & Telecommunication Engineering student at RUET.

## 🚀 Features

- **Modern & Responsive UI**: Fully responsive layout designed with Tailwind CSS, ensuring a seamless experience across desktop, tablet, and mobile devices.
- **Dark/Light Mode**: Built-in support for theme switching with automatic system preference detection.
- **Dynamic Routing**: Smooth client-side navigation powered by React Router.
- **Showcase Sections**:
  - `Home`: Introduction and quick links
  - `About`: Background and key highlights
  - `Projects`: Featured work with source code links
  - `Skills`: Categorized technical skill levels
  - `Experience & Education`: Timeline of professional and academic journey
  - `Certifications & Activities`: Extracurricular involvements
  - `Contact`: Direct contact methods and social links
- **Email Integration**: Direct email capability through UI interaction.

## 🛠️ Tech Stack

- **Framework**: [React](https://reactjs.org/) (built with [Vite](https://vitejs.dev/))
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/) & [React Icons](https://react-icons.github.io/react-icons/)
- **Routing**: [React Router](https://reactrouter.com/)
- **Typography**: Poppins & Raleway (via Google Fonts)

## 🏃‍♂️ Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You need to have Node.js installed on your machine.
- [Node.js](https://nodejs.org/en/download/) (v16.x or later recommended)

### Installation

1. Clone the repository
   ```sh
   git clone https://github.com/tanjim079/protfolio.git
   ```
2. Navigate to the project directory
   ```sh
   cd protfolio
   ```
3. Install NPM packages
   ```sh
   npm install
   ```
4. Start the development server
   ```sh
   npm run dev
   ```
5. Open your browser and visit `http://localhost:5173`
